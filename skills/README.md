## Как использовать навык

```bash

cat skills/<skill-name>.md

# 2. Следовать MCP Usage Pattern
# 3. Выполнить тестовый вызов из раздела "Пример тестового вызова"
# 4. Проверить результат по выходной схеме
```

## Как добавить новый навык

1. Создать файл `skills/<skill-name>.md` по шаблону выше
2. Добавить запись в этот `README.md`
3. Зарегистрировать в MCP памяти:
   ```bash
   mem_save(type:pattern, title:"Skill: <skill-name> v<version>")
   ctx_knowledge(remember, key:"skill-<skill-name>-v<version>")
   ```
